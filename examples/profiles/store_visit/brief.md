# 商业探店视频复刻需求

本 brief 给人和 Agent 快速阅读；机器权威事实以 `input/input.json`、`project.json` 和 `handoff/*.json` 为准。

## 必须保留

- 9:16 画幅、镜头数量、顺序、时长与切点；
- 开场钩子、进店、环境展示、菜品体验、价格或地址、CTA 的叙事结构；
- 运镜、动作节奏、转场、字幕样式、BGM 卡点和音效落点。

## 本次替换

- 出镜人物：使用已授权的正面照和半身照，全片保持同人同服装；
- 门店场景：使用已授权的门头、店内环境和餐桌素材；
- 菜品和品牌：使用实际菜品图、Logo 与核准菜单；
- 文案：只使用 `approved-claims.md` 中经过核验的价格、地址、营业时间和卖点。

## 验收

- 门头文字、Logo、菜品外观、价格和地址正确；
- 人物跨镜头一致，音画同步，字幕在手机上可读；
- 原视频结构不变，未使用无授权肖像、音乐或他人 footage；
- 付费视频生成前先 dry run 或提交预算，取得用户明确确认；
- 发布遵守平台 AI 内容标识要求。

## 禁止

- 不在 JSON、Markdown、交接或任务中写入 API Key、Token 或密码，只记录环境变量名；
- 不把 `unknown` 授权状态当作已授权；
- 不把模型生成的文件当作真实门店、菜品或人物授权材料。
